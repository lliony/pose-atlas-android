# 原图比例卡片与图片翻面交互

## 来源与优先级

用户在本次会话确认：按原图比例完整显示，长卡片随列表滚动，不裁切图片。视觉参考为 `~/Downloads/pose-atlas-new-ui.html`。实施计划见[配套计划](../plans/2026-10-25-adaptive-card-interaction.md)。本文已在当前工作区实施，验证记录见下文。

HTML 的 `renderCards()` 用 `ratio` 计算图片框 `aspect-ratio`，卡片没有统一高度。原稿图片和正文调用 `openDetail()`，详情按钮使用 `stopPropagation()`；图片白边、右上角图标选择以及图片点击翻面，以用户最新要求覆盖原稿。

[原手机布局规格](manual-crop-ui.md)中的固定 4:3 和不同图片正面等高要求，现由本文替代；原裁切、保存、AI、打印等其他要求继续有效。

## 验收规格

1. 当前页图片使用 `photoAspect(photo)` 的有效原图比例；换图后随当前图比例更新。保留 `PhotoView` 默认 Fit，不使用 Crop，不写入新图片、不修改尺寸或 panel 数据。不设置统一图片高度或最大高度；长卡片由外层列表滚动浏览。
2. 卡片四周使用 12dp 内边距；浅色卡片的表面为白色，图片圆角 18dp、外卡片圆角 26dp。深色主题使用现有 surface 色作为留白，避免出现白色刺眼外框。留白必须来自 padding，不能用 Fit 形成的灰色空带代替。
3. 详情和添加控件覆盖在照片右上角，与照片同属翻转图层，不再占用独立顶部操作行。触控区各为 48dp、无额外间距，距图片边缘 8dp；使用透明背景、白色主体配深色轮廓的 OpenInFull 与 Add / CheckCircle 图标，保留 checked 语义。编号移到正文首行，页码保留在分页行，避免紧凑卡的覆盖图标与标签相互遮挡。
4. 点击图片进入教学背面，不能打开详情。详情图标只打开详情；选择图标只修改 selected 集合；二者不能触发翻面或彼此操作。保留正文点击详情和长按选择行为，避免破坏现有快捷入口。
5. 点击照片翻到教学背面，再点击背面返回正面，可往返操作；背面使用 Compose 点击手势，让拖动继续交给列表滚动。移除底部翻面按钮和顶部返回图标；详情与添加仅覆盖在正面照片上，随正面一起翻走。翻转继续尊重系统动画开关。
6. 保留多图上一张/下一张与页码、搜索、筛选、多选批量操作、回收站、卡片册、详情编辑和 AI 浮层。正文取消只为等高设置的 minLines，保留标题最多两行、摘要最多三行，完整内容仍在详情和教学面。
7. 只改变图鉴卡片呈现；不改数据库、图片存储、手动裁切、PDF/分享、依赖版本或其他页面导航。Android minSdk 26，compileSdk/targetSdk 35，Kotlin 2.1.20，Compose BOM 2025.04.01。

## 必须通过的验证

- 原图比例矩阵：9:16、1:1、3:4、16:9、2:3、4:3；图片宽高比误差不超过 0.02。
- 图片左、右、顶部及卡片底部至少 12dp 内边距；详情与添加操作区完全位于图片边界内。
- 同一图片修改为长编号不改变布局高度；不同图片比例允许、并应产生不同图片高度。
- 图像点击、背面点击、详情点击和选择切换分别验证，没有事件串联。
- 手机 360×640dp 与正常尺寸、140dp 紧凑卡、横屏、深色、1.3 倍字号和关闭动画；长卡片可以滚动到正文与操作入口。
- 自动测试、Lint 和 Debug 构建通过后，保存模拟器截图；真实 AI 请求和打印不作为此次 UI 验收前提。
