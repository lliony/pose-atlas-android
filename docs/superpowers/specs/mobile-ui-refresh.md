# 手机界面调整

用户要求：手机一行一张卡片，设置放在最右侧，模型推荐以应用内浮窗展示。

## 设计和实现

- 沿用 Kotlin / Jetpack Compose 和纸本视觉，不因技能中的 React Native 示例迁移技术栈。
- 小于 600 dp 的手机宽度使用固定单列；平板保留自适应网格与双栏。卡片左右留白 16 dp，标题和教学摘要提高字号。
- 底部导航顺序为图鉴、卡片册、设置；类型化路由匹配当前项，兼容 R8 混淆。侧边导航同步顺序。
- 图鉴与卡片册提供“模型推荐”悬浮按钮，位于底栏上方。点击打开可滚动底部浮层，含关闭、模型配置、描述、参考图、范围、结果与取消请求入口。
- 浮层收起后保留本次输入、图片与结果；状态由 ViewModel 托管，配置变更时保留，进程结束后不保留。打开卡片详情或模型设置时先收起浮层。
- 使用应用内浮层，不申请系统悬浮窗权限。错误 Snackbar 在浮层内显示，键盘出现时内容可滚动。
- 移除顶部重复系统栏间距；推荐按钮和导航选中态使用统一纸本/暗房语义色。
- 列表底部预留悬浮按钮空间，避免最后一张卡的操作被挡住；大字体搜索占位文字单行省略。

## 技能应用

使用用户提供的 UI/UX Pro Max：原生控件、48 dp 触控区域、4/8 dp 间距、安全区、可关闭浮层、明确选中态、浅深色语义色。
本机 scripts/data 是失效的相对路径占位文件，无法执行 --design-system 搜索；依据已提供规则和现有视觉系统实施，不伪造搜索结果。
