# 姿势图鉴 Android v1.0.0-beta.1

首个 Beta 测试版本，支持 Android 8.0（API 26）及以上。

## 功能

- 离线图鉴、单列卡片、搜索筛选、翻面、多图编辑与草稿恢复。
- 统一 4:3 图片展示框，完整保留原图比例；圆形星光推荐入口与应用内推荐浮层。
- 全屏手动裁切：八种比例、拖动、双指缩放、滑块、九宫格和重置；取消保留原图，保存失败可重试。
- 编辑页顶部 AI 填充，支持取消、撤销及仅填空字段；服务地址、模型与密钥需自行配置。
- 分类、回收站、卡片册、ZIP 备份，以及 PDF/PNG 导出分享与系统打印入口。

## 安装

![扫码下载 Beta APK](https://github.com/lliony/pose-atlas-android/releases/download/v1.0.0-beta.1/beta-download-qr.png)

二维码指向本版本 APK 下载地址；私有仓库需要在浏览器登录有访问权限的 GitHub 账号。

下载发布附件 `pose-atlas-1.0.0-beta.1-debug.apk`，在 Android 上允许来源应用安装后打开 APK。`SHA256SUMS.txt` 提供附件校验值。

此 APK 使用本地调试证书签名，供 Beta 测试，包含调试能力，不是生产签名版本。与之前交付的本地 Debug APK 使用相同证书，可覆盖安装。未来更换正式签名时可能需要卸载重装，请先通过应用内 ZIP 备份保存数据。

## 验证与限制

- 46 项 JVM 测试通过，Lint 无错误（55 条警告），Debug/Release 构建成功。
- 同一功能实现已在 Android 15 / API 35 模拟器通过 6 项设备测试，覆盖裁切、EXIF/panel、PDF、Keystore 等；该轮设备测试发生在版本名改为 Beta 之前。
- 截图附件展示主界面、顶部 AI 填充及手动裁切。
- 尚未验收实体手机打印、分享接收端、TalkBack、真实大图库性能及用户模型服务；卡片册拖拽和部分字段错误定位待完善，PNG 页脚尺寸标签的单位换算待校正。
- 旧 JSON 导入受设备内存预算限制，大备份请使用 ZIP；强杀进程时文件与数据库的联合恢复尚无持久日志保证。

仓库保持私有，发布附件仅对有仓库访问权限的用户可见。
