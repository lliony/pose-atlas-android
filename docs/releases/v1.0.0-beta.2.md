# 姿势图鉴 Android v1.0.0-beta.2

本次更新包含暖白主题与卡片交互调整，支持 Android 8.0（API 26）及以上。

## 更新

- 应用统一暖白与橙红主题。
- 卡片按照片原始比例展示，保留白边；长卡片随列表滚动。
- 照片右上角使用紧凑的透明详情、添加/选中图标，白色图标配深色轮廓。
- 点击照片翻到教学背面，再次点击翻回；整张卡片包含边框进行翻转动画，操作按钮随照片翻转。
- 新增姿势页的 AI 填充移到添加照片下方。

## 安装

![扫码下载 Beta APK](https://github.com/lliony/pose-atlas-android/releases/download/v1.0.0-beta.2/beta-download-qr.png)

下载附件 `pose-atlas-1.0.0-beta.2-debug.apk`，允许来源应用安装后打开 APK。仓库公开，无需登录 GitHub。附件 `SHA256SUMS.txt` 提供校验值。

本包为调试签名 Beta 测试版，包含调试能力，不是生产签名版本。

**从旧 Release beta.1 升级：签名不同，无法直接覆盖安装。必须先在旧应用中导出 ZIP 备份并确认文件已保存，再卸载旧版、安装新版并导入备份。直接卸载会删除本地数据。**

已核验新旧 APK 签名，新版使用本机保留的调试证书；当前未找到旧 Release 包对应的签名密钥。

## 验证与限制

- 本版重新通过 50 项 JVM 测试、Lint（0 错误）和 Debug 构建；已验证应用版本为 1.0.0-beta.2、versionCode 为 2。
- 相同 UI 实现在版本号更新前通过 4 项相关设备用例（交互隔离、草稿恢复、图片比例与整卡双向翻转）。
