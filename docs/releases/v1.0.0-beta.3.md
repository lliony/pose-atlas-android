# 姿势图鉴 Android v1.0.0-beta.3

本次更新应用图标、多图详情浏览和卡片册图片展示，支持 Android 8.0（API 26）及以上。

## 更新

- 使用暖橙背景、奶油白高领服饰的动漫人物应用图标，适配系统桌面裁切。
- 修复多图详情纵向堆叠：同一区域左右滑动切换照片，教学与分享同步跟随当前图片。
- 照片上的详情按钮改为右上箭头，详情与选中按钮统一黑底白图标。
- 卡片册显示首张有效卡片的封面，册内每张卡片显示小预览图。
- 封面与缩略图居中裁切铺满，消除空边；详情页保留完整图片。

## 安装与升级

![扫码下载 Beta APK](https://github.com/lliony/pose-atlas-android/releases/download/v1.0.0-beta.3/beta-download-qr.png)

下载附件 `pose-atlas-1.0.0-beta.3-debug.apk`。公开下载无需登录，`SHA256SUMS.txt` 提供校验值。

从 beta.2 升级使用相同调试签名，可直接覆盖安装，保留应用数据。建议升级前通过应用内 ZIP 备份。

**从旧 Release beta.1 升级：签名不同，不能直接覆盖。必须先在旧应用中导出 ZIP 备份并确认保存，再卸载旧版、安装新版并导入。直接卸载会删除本地数据。**
