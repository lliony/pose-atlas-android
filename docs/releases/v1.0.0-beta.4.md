# 姿势图鉴 Android v1.0.0-beta.4

本次更新应用内检查更新、AI 接口格式和照片卡片展示，支持 Android 8.0（API 26）及以上。

## 更新

- 设置中新增检查更新、下载进度、取消与重试，校验安装包后由系统确认覆盖安装。
- AI 模型档案支持 OpenAI Chat Completions 和 Anthropic Messages，旧配置默认 OpenAI。
- AI 推荐以照片卡片展示，点击查看详情；返回时恢复原推荐窗口和滚动位置。
- 照片铺满卡片，编号与标题浮于照片上；操作按钮采用浅色半透明底，无描边。
- 修复详情长图与文字区域重叠，长图保持原比例随页面滚动。
- 保留主分支的工作区、编辑及 AI 配置架构调整。

## 安装与升级

![扫码下载 Beta APK](https://github.com/lliony/pose-atlas-android/releases/download/v1.0.0-beta.4/beta-download-qr.png)

下载附件 `pose-atlas-1.0.0-beta.4-debug.apk`，`SHA256SUMS.txt` 提供校验值。

Beta.2 / Beta.3 使用相同调试签名，可覆盖安装并保留资料，升级前建议导出 ZIP 备份。旧版本尚无应用内更新入口，需先手动安装本版。

Beta.1 的旧发布包签名不同：请先导出并保存 ZIP 备份，再卸载旧版、安装新版并导入；直接卸载会删除本地资料。

## 验证与限制

- 本地 90 项 JVM 自动测试、10 项 API 36 模拟器自动测试、Lint、Debug APK 和设备测试 APK 构建通过。
- 此包为调试签名 Beta 测试版。实体手机、真实 AI 服务、物理打印尚未验收。
