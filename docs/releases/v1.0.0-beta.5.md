# 姿势图鉴 Android v1.0.0-beta.5

本次增加本机相机拍摄入口，支持 Android 8.0（API 26）及以上。

## 更新

- AI 推荐的场景适配与参考图匹配支持选择“从相册选择”或“拍摄照片”。
- 新建、编辑卡片时也可调起手机本机相机，保留相册多选与每张卡片最多 20 张图片的限制。
- 拍摄确认后自动返回并导入原图；取消拍摄不改动当前图片。导入继续处理 EXIF 方向，拍摄临时文件在完成或取消后清理。
- 保存待拍摄文件位置，支持相机打开期间 Activity 重建后接收拍摄结果。

## 安装与升级

![扫码下载 Beta APK](https://github.com/lliony/pose-atlas-android/releases/download/v1.0.0-beta.5/beta-download-qr.png)

下载附件 `pose-atlas-1.0.0-beta.5-debug.apk`，`SHA256SUMS.txt` 提供校验值。

本版与 GitHub 当前 Beta.4 附件签名一致，可直接覆盖升级并保留应用数据。签名 SHA-256：`61e301df093143f71afedfe4df7ef8f421427ed720658764ecec1fc8e6599ee8`。

其他不同签名的旧安装包无法直接覆盖；请先在旧应用中导出 ZIP 备份并确认保存，再卸载旧版、安装新版并导入。直接卸载会删除本地资料。

## 验证与限制

- 92 项 JVM 自动测试、Lint、Debug APK 和设备测试 APK 构建通过；相机回归覆盖拍摄导入、取消保留原图及 Activity 重建后返回。
- API 36 模拟器已验证系统相机启动、拍摄确认、返回和图片导入。
- 此包为调试签名 Beta 测试版。实体手机相机兼容性与系统杀死进程后的恢复尚未验收。
